# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.3.0] — 2026-10-11

### Удалено
- Вкладка «Инструменты» целиком: очистка кэша Discord, обновление hosts от автора, замена
  служебных файлов движка. Замена фейков требовала повтора после каждого обновления движка —
  вещи, о которой пользователь обязан был помнить сам.
- Вкладка «Диагностика» целиком: A/B-проверка цели, вердикт, кнопка «Применить».
- Настройка «Фильтр стратегии» (домены/IP): дублировала «ipsets» и настраивала аргументы
  запуска, тогда как «ipsets» меняет содержимое списка. Осталось то, что реально влияет.
- Проверка скорости DNS-серверов вместе с сетевым кодом замера.
- Шифрование DNS (DoH): Windows всё равно слала запросы открытым текстом, обещание в меню
  не выполнялось. Вкладка теперь только подставляет выбранные адреса и ничего не обещает.
- Поле «Сетевой адаптер» в DNS — адаптер определяется автоматически.
- Движок DPIBreak: лицензия GPLv3, распространять его внутри MIT-пакета нельзя.

### Добавлено
- Выбранный DNS сохраняется между запусками программы.
- Полные тексты лицензий сторонних компонентов (движки, WinDivert, иконки, узоры) лежат в
  репозитории: `THIRD_PARTY_NOTICES.md` и папка `licenses/`. В самом комплекте — только
  `zgui.exe` и `data\`.

### Исправлено
- Блокировка операций реально держалась на время теста и обновления: гард отпускался с
  возвратом команды, и «Восстановить интернет» можно было запустить посреди прогона.
- Секрет Telegram-моста не отдаётся в интерфейс (на диске остаётся).
- `state.json`: атомарная запись с fsync; непрочитанный или битый файл больше не затирается
  дефолтами молча.
- Обновление программы больше не может скачать архив движка вместо архива программы.
- Имя файла из архива больше не может указать путь вне папки данных.
- Журнал: русские сообщения без префикса `Error:`, список не перерисовывается на каждую
  строку, каждая строка попадает в список один раз.
- Тест стратегий: кнопки запуска и остановки гаснут на время прогона; снятие выделения
  больше не запускает все стратегии вместо выбранных.
- Контекстное меню работает на выделенном тексте.
- Предложение обучения больше не гасит предложение Telegram-моста.

## [1.2.0] — 2026-10-04

### Добавлено
- Автозапуск при входе: одна галочка ставит службу и заводит программу в трей при старте
  системы — окно появляется по клику на иконку.
- Узоры фона во «Внешнем виде»: три узора (топо, пузыри, крестики-нолики) с настройкой
  прозрачности.
- Галочки «Отключить анимацию темы» и «Отключить узор темы» (в светлой теме недоступны).

### Исправлено
- Повторный запуск из трея поднимает окно уже запущенной копии (раньше оставалось скрытым).
- Диалог обучения больше не появляется повторно после перезапуска (флаг сохраняется при
  сохранении настроек).
- Плитка «Обновление программы» качала не тот архив: среди ассетов релиза выбирался
  `engine-zapret2.zip` вместо архива программы. Теперь выбирается zip с именем программы
  (`Z-GUI …`/`… Stable …`), служебные `engine-*.zip` пропускаются.

## [1.1.0] — 2026-09-30

### Добавлено
- Обучение при первом запуске: интерактивные подсказки поверх интерфейса (тест стратегий →
  выбор движка → запуск → служба → остановка) и кнопка «Пройти обучение снова» в «Настройках».
- Трей: свёртывание в трей, одна копия на систему (повторный запуск поднимает окно).
- Плитка «Обновление программы» в «Обновлениях»: проверка новой версии и скачивание архива.
- «Диагностика»: помогает понять, почему сайт не открывается, и что можно сделать; отмена и
  возврат прежней стратегии после проверок.
- Дельта списков при обновлении (было / стало / добавлено).
- Переключатель фильтра стратегии «по доменам ↔ по IP».
- Античит-пауза (опция): автоматическая остановка при запуске игровых античитов.
- Журнал запуска по секциям: система / конфиг / вывод движка / стоп.
- Инструкция по Telegram — нативной вёрсткой, подстраивается под тему.

### Изменено
- Название приложения — «Z-GUI» (поддерживается четыре движка).
- Тексты без обещаний повторного запроса прав администратора (права запрашиваются один раз).
- Секрет Telegram-моста генерируется системным генератором случайных чисел.

### Исправлено
- Одна копия: закрытие старых копий не затрагивает фоновый тест; повторный запуск поднимает окно.
- Античит-пауза: без повторов и с блокировкой операций.
- «Диагностика»: работает отмена, прежняя стратегия возвращается после проверок.
- «Диагностика»: кнопки не пересекаются; более точные выводы.
- Обновления: проверка имени и размера скачиваемого архива.
