## Critical (5)

### 1. `telegram.rs:119-121` — бинд-ошибка не пробрасывается
`listen_tx` уже `take`-нут в замыкании (строка 102), поэтому ветка на строке 119 **никогда не выполняется**. Пользователь видит "не запустился за 20 сек" вместо реального сообщения.  
**Правка:** пробрасывать ошибку бинда через отдельный `oneshot::channel`.

### 2. `service.rs:104` — `tasklist` CSV парсится через `split("\",\"")`
Разбор CSV через `line.split("\",\"")` ломается на именах процессов с запятой. Процесс молча пропускается.  
**Правка:** использовать `csv` crate или `line.splitn(2, ',')` с удалением кавычек.

### 3. `updater.rs:327` — `archive.record` пишется при неудаче `atomic_write`
`archive.record` вызывается даже если `atomic_write` вернул `Err`. Следующий check покажет "ok", а файл — старый/битый.  
**Правка:** переместить `archive.record` внутрь `Ok`-ветки.

### 4. `service.rs:369` — `GetFileNameWithoutExtension` + `split(' ')` ломается на пробелах
`$_.PathName -replace '"',''` затем `-split ' '`. Если путь содержит пробел, получаем фрагмент вместо полного имени.  
**Правка:** парсить PathName регуляркой `^"([^"]+)"`.

### 5. `runner.rs:135-151` — утечка `.ps1` при панике в `run_script_privileged`
Временный `.ps1` удаляется только после успешного возврата. Если elevated-скрипт паникует или процесс убит, файл остаётся в `logs/`.  
**Правка:** RA-гвард для `fs::remove_file`.

## Important (8)

### 6. `lib.rs:2657` — `wants_presets` при `ids.is_empty()`
`ids.is_empty()` конвертирует "все файловые записи" в "+пресеты".  
**Правка:** разделить флаг "применить всё" и "применить пресеты".

### 7. `updater.rs:290` — `apply_updates` перезапрашивает remote hash
`apply_updates` снова вызывает `check_entry`, который делает `fetch_bytes` — дублирование сетевых запросов.  
**Правка:** передавать результаты `check_all` в `apply_updates`.

### 8. `lib.rs:2672-2777` — `file_err` молчит в итоговом тосте
Если файлы не применились, а пресеты — да, пользователь видит "обновлено: N" без упоминания ошибки.  
**Правка:** агрегировать `file_err` в тост/лог.

### 9. `service.rs:447-449` — `ps_single_quote` не экранирует `$`, `` ` ``
Имена процессов с `$` или `` ` `` инжектируются в админский PS-скрипт.  
**Правка:** добавить экранирование в `ps_single_quote`.

### 10. `service.rs:433-438` — `build_service_cmdline` квотирует только пробел
Не обрабатывает табуляцию, новую строку, вложенные кавычки.  
**Правка:** расширить на все whitespace-символы.

### 11. `tester.rs:376-543` — `@` в аргументах не квотируется
PowerShell использует `@` для splatting.  
**Правка:** добавить `@` в регулярку квотирования.

### 12. `lib.rs:2672-2777` — `apply_updates` не атомарна
Если файлы применились, а пресеты — нет, state в частично-применённом виде. Нет rollback.  
**Правка:** документировать или оборачивать в транзакцию.

### 13. `netreset.rs:172-191` — `reset()` возвращает жёстко зашитые `steps`
Даже если `run_script_privileged` вернул `Err`, функция возвращает `NetResetResult` с успешными шагами.  
**Правка:** парсить `Write-Output 'STEP:...'` из вывода скрипта.

## Verified and Correct

1. **Порядок блокировок** — `OPS` -> `testing` -> `state`; дедлоков нет.
2. **Одна операция за раз** — `ops_try()` + `op_running` снимается во всех ветках.
3. **Персистентность** — `Roots` round-trip (плоский + `{"map":{...}}` + легаси); бэкап `.bad-<ts>`.
4. **Пути с пробелами** — квотинг в `write_launcher`, `build_service_cmdline`, `run_script_privileged`.
5. **Не доверять вводу** — имена процессов в PS-массивы `@('...')` с экранированием.
6. **Тест-раннер** — маркеры корректны; гашение при выходе через `RunEvent::Exit`.
7. **Реестр движков** — нет остаточных хардкодов; `exe_name` через `EngineDef`.
8. **Фронт <-> бекенд** — все 54 `invoke("...")` имеют обработчики; Bootstrap camelCase.
9. **OTA-пресеты** — `apply_preset_set` трогает только `builtin`; кастомные не трогаются.
10. **Мост тест<->автоподбор** — `args_key` + 1 час + только `started`.
11. **Kill script** — PID+имена, стоп/удаление служб, двойная попытка, идемпотентность.
12. **`run_script_privileged`** — "уже админ" -> прямой запуск; иначе UAC.
